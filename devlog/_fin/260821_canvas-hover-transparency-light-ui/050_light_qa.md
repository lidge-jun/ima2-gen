# 050 — 라이트 모드 전면 QA / 색감 보정 (wp5)

## 목표

주요 화면 전부(클래식 생성, 노드 캔버스, 캔버스 모드, 카드뉴스, 설정, 갤러리,
모바일 폭)를 라이트 모드로 순회하며 대비/색감 결함을 보정한다.

## 방법

- chrome으로 각 화면 라이트/다크 스크린샷 → view_image 검사
- 검사 항목: 대비(AA), 그림자/오버레이 반전 누락, 하드코딩 잔재, 아이콘 가시성,
  스크롤바/셀렉션 색, 이미지 투명 체커보드 가시성
- opus 서브에이전트에 스크린샷 경로 + 코드 diff를 주고 색감 리뷰 → 지적사항 반영

## 검증

- 전 화면 라이트 스크린샷 세트 + opus PASS 평결
