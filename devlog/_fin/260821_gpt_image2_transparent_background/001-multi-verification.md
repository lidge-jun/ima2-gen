## 대조군 — 기존 갤러리 이미지 전량

같은 배치 스크립트로 `~/.ima2/generated`의 과거 이미지를 측정하면
**예외 없이 `channels=3, hasAlpha=false`** 가 나온다 (2026-07-30 ~ 2026-08-21 이전 생성분).
즉 알파는 ima2가 늘 만들던 것이 아니라 이번 프롬프트 넛지 경로에서만 발생한다.
장면형 프롬프트 대조군(`나무 식탁 위 사과`)도 `channels=3`으로 나왔다
(000 문서 §4). **넛지가 레버라는 것이 양방향으로 증명됐다.**

## 한글 렌더링 — gpt-image-2 판별

사용자 제안 판별법: 한글이 많은 이미지를 뽑아 깨지지 않으면 gpt-image-2다.

생성 포스터의 실제 렌더링 텍스트 (육안 확인):
- 대제목 "투명 배경 지원 시작" — 정확
- 중간 "이마투 생성 스튜디오" — 정확
- 하단 "한글 렌더링 정확도 검증용 이미지입니다" — 정확

받침이 복잡한 글자(**렌더링, 정확도, 검증, 스튜디오, 지원**)까지 오탈자·자소분리·
왜곡 없이 렌더링됐고, 동시에 배경은 알파 0이다.
구세대 이미지 모델의 전형적 실패(자소 분리, 가짜 한글 글리프, 획 뭉개짐)가 없다.

**판정: OAuth 경로의 이미지 백엔드는 gpt-image-2 계열이 맞다.**
응답 tools 에코의 `model: "gpt-image-2-codex"`와 일치한다 (000 §2).

## 종합 결론

1. gpt-image-2 투명 배경은 **OAuth 경로에서 오늘 동작한다.** API 키 불필요.
2. 조건은 `background` 강제가 아니라 `auto` + 프롬프트 의도다.
3. 한글 텍스트 렌더링 품질이 gpt-image-2임을 교차 확인해 준다.
4. 반투명(유리·잎맥)까지 부분 알파로 살아있다 — 단순 이진 마스크가 아니다.
