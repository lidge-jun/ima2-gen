## 수정 (wp3)

- **L1/L2**: `storeReferenceImpl.ts`에 `resolveModelReferenceSrc()` 추가 —
  canvas version이면 `/generated/<canvasSourceFilename>`(clean)으로 라우팅.
  계약 테스트 2건을 새 계약으로 갱신(압축 경유 유지 + clean 라우팅 고정).
- **G2**: Apply 시 memo 지시문을 `insertPromptToComposer` 칩("캔버스 노트",
  `canvas-annotations:<source>` id, placement after)으로 삽입. 재적용 시 교체,
  노트 없으면 제거. 사용자가 칩을 지워 옵트아웃 가능.
- **G3**: `memoPrompt.ts` 지시문 3단 강화 — (1) 서두: "임시 편집 지시,
  이미지 내용 아님", (2) 넘버링+위치 지시 목록(기존 유지), (3) 말미: 적용 후
  마크업 전부 제거 + 가려진 영역을 주변 질감/조명/원근에 맞게 재구성 + 잔존물
  금지, (4) 미지정 요소 보존 조항. 테스트 고정 문장
  "Do not render any annotation text..." 보존.
- 문서: `PROMPT_STUDIO(.ko).md`에 "캔버스 노트와 i2i" 섹션,
  `skills/ima2/SKILL.md`에 Annotated inputs / Removal edits 지침.

## 후속 과제 (G1, 제품 결정 필요)

구워진 노트의 사후 제거(버전 되돌리기/재편집)는 배경 클린업 픽셀 파이프라인과
주석 벡터 파이프라인이 같은 버전 슬롯을 공유해 단순 rebase가 안 된다.
옵션: (a) 버전 revert 버튼(클린 소스로 재시작), (b) 주석 draft를 apply 후에도
보존하고 캔버스 베이스를 clean+벡터로 재구성(클린업 편집과 충돌 해결 필요),
(c) 버전에 provenance 마커 추가로 (b)를 주석-전용 버전에만 적용.
