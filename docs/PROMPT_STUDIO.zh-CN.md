# 提示工作室手册

Prompt Studio 是用于重复图像迭代的经典工作区配置文件。它
使图像查看器位于中心，最近几代位于侧面，而
作曲家加上接近当前图像的生成控件。

当您不确定 Prompt Studio 控件的作用或何时
您需要一种可重复的方法来报告工作区问题。

## 特征图

|区域|它的作用|笔记|
|---|---|---|
|作曲家|保留下一个请求的提示。|选择现有图像仅供查看。它不应该覆盖作曲家。|
|故事板|在连续帧之间保持角色和场景的连续性。|切换作曲家。适用于图像和视频生成；图像关键帧是为视频制作而组合的。|
|多模|从当前提示启动多个单独的图像请求。|每个槽都是候选输出，而不是拼贴面板或保证的场景序列。|
|1:1直接|通过应用程序更少的重写来发送提示。|将其用于精确的措辞、严格的提示实验或提供者端提示语法。|
|模型快捷菜单|从侧边栏标题更改图像模型和推理工作。|完整的设置工作区仍然是详细的配置页面。|
|最近几代|显示可见的 Prompt Studio 历史域。|箭头键在同一可见的最近域内移动，而不是隐藏的旧行。视频项目呈现为视频缩略图。将任何缩略图拖到编辑器中以将其添加为参考图像。视频结果显示“第一帧”、“中间帧”和“最后一帧”按钮以复制关键帧。|
|视频设置|控制Grok视频时长、分辨率、宽高比和规划器模型。|默认规划器模型是`grok-4.3`；`grok-4.6`和`grok-4.5`可选。|
|画廊|浏览保存的本地图像、所有/收藏夹选项卡和文件夹。|最喜欢的切换应保留您正在浏览的图库视口。|
|提示库|有意将保存的提示文本导入到编辑器中。|库插入/继续操作是显式提示导入；被动图像选择则不然。|

## 多模式提示

多模式在多个候选时隙上重复生成请求形状。
当您需要替代品时，而不是当您需要组合一种时，它很有用
多面板图像。

对于相关候选人，将共同主题放在首位，并制定变化规则
第二：

```text
Same character design in every image: a silver-haired courier in a red raincoat.
Make 4 alternatives that vary only camera angle, lighting, and background street.
Keep face, outfit, age, and color palette consistent.
```

对于不相关的候选人，直接说：

```text
Create 4 unrelated sticker ideas for a local image generation app.
Each image should use a different mascot, color palette, and composition.
```

如果您需要真正的两幅漫画、联系表、前后比较，或
拼贴，在单个普通图像请求中请求，而不是依赖
多模插槽：

```text
Create one 2-panel comparison image. Left panel: rough sketch UI. Right panel:
polished Prompt Studio UI. Add small labels inside each panel.
```

## 直接模式

使用**1:1直接**当确切的提示文本很重要时。它有助于：

- 比较提示措辞的变化，
- 保留结构化提示模板，
- 使用提供者特定的指导风格，
- 避免在故障排除期间更改应用程序端措辞。

直接模式可以与多模式一起使用。在这种情况下，每个多模
slot 接收相同的直接提示请求形状。

## 推理努力

推理工作量控制所选模型之前可能花费的规划量
或在生成期间。从日常工作的默认设置开始。当
提示有许多限制、参考或作文要求。

侧边栏模型标签可打开模型和推理的快速设置。这
设置工作区仍然显示完整的模型配置和说明
复制。

## 画廊和提示安全

Prompt Studio 将浏览与创作分开：

- 被动图像选择仅供查看。
- 单击历史或图库图像会聚焦图像以供查看。
- 收藏夹开/关会更改保存的图像元数据，并且不应跳转您的
画廊浏览位置。
- “全部”和“收藏夹”选项卡是浏览过滤器。在它们之间切换确实
不是故意导入提示。
- 提示库插入、“从该图像继续”以及明确的重用操作
是有意改变作曲家的行为。

在生成之前，如果您使用的是显式提示，请浏览一下 Composer
导入动作。被动图像选择不应影响您的草稿。

## 报告提示 Studio 问题

打开问题时，请包括：

- `ima2-gen`版本和操作系统，
- 浏览器和视口大小（如果涉及布局），
- 工作区配置文件、模式切换、模型、推理工作和图像计数，
- 从新鲜开始编号步骤`ima2 serve`会议，
- 问题是否发生在“全部”、“收藏夹”或“最近历史记录”中，
- 安全的屏幕截图或屏幕录制（如果它们不泄露私人提示）。

请勿分享ChatGPT曲奇饼，OAuth令牌文件，API键，原始上游
响应、私人提示历史记录或生成的 Base64 数据。

## Canvas 笔记和 I2I 编辑

当您在画布上绘制备忘录（注释）、箭头或方框并保存时，
注释到达模型为**文本指令，而不是像素**.

- 保存画布版本可保留烧录的注释图像UI展示
仅历史；模型参考始终使用**干净的来源**。添加
当前图像作为参考也会将画布版本替换为其
原来的。
- 注释内容作为可移动的“画布注释”芯片附加到作曲家，因此
下一代携带指令（位置+内容+
标记删除规则）。
- 绘制框并运行蒙版编辑调用编辑API与干净的
来源、盒子面罩和注释说明。

如果标记仍然出现在结果中：

- 短语注释为**那个地方应该能看到什么**，不仅仅是做什么
消除。例如，“显示连续的木质桌子表面，其中
便签是”而不是“删除便签”。
- 根据同一请求生成多个候选者并选择最干净的。
- 仅对残留迹线进行装箱，然后再运行一次掩模编辑。

### 恢复烘焙笔记

包含烘焙笔记的画布版本提供**恢复烘焙笔记**。当没有
后来添加了像素编辑，恢复了干净的源并保存了注释
作为可编辑草稿返回。如果背景清理或其他像素编辑是
之后添加，Prompt Studio 要求确认，因为也会恢复
丢弃那些像素编辑。
