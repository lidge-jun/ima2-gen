# 提示工作室手冊

Prompt Studio 是用於重複影像迭代的經典工作區設定檔。它
使影像檢視器位於中心，最近幾代位於側面，而
作曲家加上接近目前影像的生成控制項。

當您不確定 Prompt Studio 控制項的作用或何時
您需要一種可重複的方法來回報工作區問題。

## 特徵圖

|區域|它的作用|筆記|
|---|---|---|
|作曲家|保留下一個請求的提示。|選擇現有影像僅供查看。它不應該覆蓋作曲家。|
|故事板|在連續幀之間保持角色和場景的連續性。|切換作曲家。適用於影像和視訊生成；影像關鍵影格是為影片製作而組合的。|
|多模|從目前提示啟動多個單獨的影像請求。|每個槽都​​是候選輸出，而不是拼貼面板或保證的場景序列。|
|1:1直接|透過應用程式更少的重寫來發送提示。|將其用於精確的措詞、嚴格的提示實驗或提供者端提示語法。|
|模型快速選單|從側邊欄標題更改圖像模型和推理工作。|完整的設定工作區仍然是詳細的配置頁面。|
|最近幾代|顯示可見的 Prompt Studio 歷史域。|箭頭鍵在同一可見的最近域內移動，而不是隱藏的舊行。影片項目呈現為影片縮圖。將任何縮圖拖曳到編輯器中以將其新增為參考圖像。影片結果顯示「第一幀」、「中間幀」和「最後一幀」按鈕以複製關鍵影格。|
|影片設定|控制Grok視訊時長、解析度、寬高比和規劃器模型。|預設規劃器模型是`grok-4.5`; `grok-4.3`仍然是兼容性覆蓋。|
|畫廊|瀏覽已儲存的本機圖像、所有/收藏夾標籤和資料夾。|最喜歡的切換應保留您正在瀏覽的圖庫視窗。|
|提示庫|有意將已儲存的提示文字匯入到編輯器中。|庫插入/繼續操作是明確提示匯入；被動影像選擇則不然。|

## 多模式提示

多模式在多個候選時隙上重複產生請求形狀。
當您需要替代品時，而不是當您需要組合一種時，它很有用
多面板影像。

對於相關候選人，將共同主題放在首位，並制定變化規則
第二：

```text
Same character design in every image: a silver-haired courier in a red raincoat.
Make 4 alternatives that vary only camera angle, lighting, and background street.
Keep face, outfit, age, and color palette consistent.
```

對於不相關的候選人，直接說：

```text
Create 4 unrelated sticker ideas for a local image generation app.
Each image should use a different mascot, color palette, and composition.
```

如果您需要真正的兩幅漫畫、聯絡表、前後比較，或
拼貼，在單一普通圖像請求中請求，而不是依賴
多模插槽：

```text
Create one 2-panel comparison image. Left panel: rough sketch UI. Right panel:
polished Prompt Studio UI. Add small labels inside each panel.
```

## 直接模式

使用**1:1直接**當確切的提示文字很重要時。它有助於：

- 比較提示措詞的變化，
- 保留結構化提示模板，
- 使用提供者特定的指導風格，
- 避免在故障排除期間更改應用程式端措辭。

直接模式可以與多模式一起使用。在這種情況下，每個多模
slot 接收相同的直接提示請求形狀。

## 推理努力

推理工作量控制所選模型之前可能花費的規劃量
或在生成期間。從日常工作的預設開始。當
提示有許多限制、參考或作文要求。

側邊欄模型標籤可開啟模型和推理的快速設定。這
設定工作區仍然顯示完整的模型配置和說明
複製。

## 圖庫和提示安全

Prompt Studio 將瀏覽與創作分開：

- 被動影像選擇僅供檢視。
- 點擊歷史或圖庫圖像會聚焦圖像以供查看。
- 收藏夾開/關會更改已儲存的圖像元數據，並且不應跳轉您的
畫廊瀏覽位置。
- “全部”和“收藏夾”選項卡是瀏覽過濾器。在它們之間切換確實
不是故意導入提示。
- 提示庫插入、「從該圖像繼續」以及明確的重複使用操作
是有意改變作曲家的行為。

在生成之前，如果您使用的是明確提示，請瀏覽 Composer
導入動作。被動圖像選擇不應影響您的草稿。

## 報告提示 Studio 問題

打開問題時，請包括：

- `ima2-gen`版本和作業系統，
- 瀏覽器和視窗大小（如果涉及佈局），
- 工作區設定檔、模式切換、模型、推理工作和圖像計數，
- 從新鮮開始編號步驟`ima2 serve`會議，
- 問題是否發生在“全部”、“收藏夾”或“最近歷史記錄”中，
- 安全的螢幕截圖或螢幕錄製（如果它們不洩露私人提示）。

請勿分享ChatGPT餅乾,OAuth令牌文件，API鍵，原始上游
回應、私人提示歷史記錄或產生的 Base64 資料。

## Canvas 筆記和 I2I 編輯

當您在畫布上繪製備忘錄（註釋）、箭頭或方框並儲存時，
註解到達模型為**文字指令，而不是像素**.

- 保存畫布版本可保留燒錄的註釋影像UI展示
僅歷史；模型參考始終使用**乾淨的來源**。添加
當前圖像作為參考也會將畫布版本替換為其
原來的。
- 註釋內容作為可移動的“畫布註釋”晶片附加到作曲家，因此
下一代攜帶指令（位置+內容+
標記刪除規則）。
- 繪製框並執行蒙版編輯呼叫編輯API與乾淨的
來源、盒子麵罩和註釋說明。

如果標記仍然出現在結果中：

- 短語註釋為**那個地方應該可以看到什麼**，不只是做什麼
消除。例如，「顯示連續的木質桌子表面，其中
便籤是」而不是「刪除便籤」。
- 根據同一請求產生多個候選者並選擇最乾淨的。
- 僅對殘留跡線進行裝箱，然後再運行一次遮罩編輯。

### 恢復烘焙筆記

包含烘焙筆記的畫布版本提供**恢復烘焙筆記**。當沒有
後來添加了像素編輯，恢復了乾淨的來源並保存了註釋
作為可編輯草稿返回。如果背景清理或其他像素編輯是
之後添加，Prompt Studio 要求確認，因為也會恢復
丟棄那些像素編輯。
